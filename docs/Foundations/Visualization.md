# Visualization

## Minimum validation widths

Visualization layouts are validated against the smallest expected width
for each supported column span.

This ensures that visualizations remain valid across supported layout
configurations without defining their minimum size as an absolute pixel value.

| Span | Minimum validation width |
|------|--------------------------|
| 3 columns | 277 px |
| 4 columns | 376 px |
| 6 columns | 574 px |
| 12 columns | 1168 px |
